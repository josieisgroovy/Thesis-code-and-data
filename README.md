Objective B
1. Example of an R script for formatting and processing one case study through MED tests using the Eckert dataset. This script is used to take SymPortal pre-MED data and reformat it running MED independently. Then, it takes MED output files and organises them into dataframes for further analysis.
2. Example of a bash script for running one MED test on one case study. This script is used in the command line to run M on the formatted dataset several times using a list of m (entropy threshold) or M (minimum substantive abundance) values. The M values go from <i>N<sub>reads</sub></i> * 0.0001 as recommended by Eren et al., (2015) to <i>N<sub>reads</sub></i> * 0.004 as used in SymPortal, to <i>N<sub>reads</sub></i> * 0.008 (double SymPortal)
3. R script for combining case studies and analysing MED output. This script builds Bray-Curtis groups for MED output datasets and constructs models
